# 全国大学生数学竞赛 · 推导课

五份资料（第 15/16/17 届数学 A 类初赛试卷与参考答案、两份讲义）整理成的 **5 门从零推导课 + 1 个五章体系总入口**。全部是单文件 HTML，KaTeX 与字体内联，离线可开。

**在线学习：** https://zrx-11.github.io/math-competition-derivation/

## 内容

| 文件 | 节数 | 内容 |
|---|---|---|
| `index.html` | — | 总入口：按五章归类 51 节、全局搜索、总进度、到各节深链 |
| `01-竞赛体系课.html` | 13 | 极限八法、一元/多元微分、级数、常微分、空间解析几何 |
| `02-微积分真题课.html` | 14 | 导数 → 隐函数 → 高阶导 → 切平面 → 定积分技巧 → 重积分 → 曲线曲面 → 格林/高斯/斯托克斯 |
| `03-第十五届A卷.html` | 8 | 2023 年初赛六题逐题推导 |
| `04-第十六届A卷.html` | 8 | 2024 年初赛六题逐题推导 |
| `05-第十七届A卷.html` | 8 | 2025 年 11 月初赛六题逐题推导 |

五章划分：极限与连续 / 微分与偏导 / 积分 / 无穷级数与常微分方程 / 空间解析几何 + 拓展（线性代数与组合计数）。

每节固定结构：前置知识 → 生活类比 → 定义 → 可折叠的完整推导（每行写清理由）→ 本节落点 → 一道自测（带答案）。

## 用法

- 本地：双击 `index.html`，无需服务器与网络。
- 进度：写在浏览器 `localStorage`（键 `mc.prog`），只在本机，不跨设备同步。
- 深链：`课程文件.html#节id`，例如 `02-微积分真题课.html#s2-12`。

## 部署

仓库 Settings → Pages → Source `Deploy from a branch`，Branch `main`、目录 `/ (root)`。根目录的 `.nojekyll` 用来阻止 Jekyll 处理，删掉会导致路径异常。

详细说明见 `交付说明.md`。
