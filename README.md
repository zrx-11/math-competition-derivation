## 知识点 ↔ 试题

每道试题都标注 1–2 个知识点（知识精讲里的具体小节）：

- 知识节底部显示「对应试题」，点一下跳到题解；
- 题解底部显示「对应知识点」，点一下跳回讲解；
- 映射表在 `_build/catalog.py` 的 `REL`，新增题目或调整归属只改这一处，重新构建即可。

## 题库持续更新

专题题库不设“精选”上限，按知识点持续补题。新增一道题的流程：

1. 在 `_build/content/l6.py` 里追加一个 `S.append(dict(...))`，字段与现有题目一致（题干、推导、易错点、自测）；
2. 在 `_build/catalog.py` 的 `REL` 里登记它对应的知识点 id（如 `s6-13: ['s2-9']`）；
3. 跑 `cd _build && python3 build.py l6 && python3 make_index.py`。

新增整卷解析时，在 `catalog.py` 的 `LESSONS` 里加一行（文件名、模块 `p`），再把该卷的节映射进 `REL`。

## 用法

- 本地：双击 `index.html`，无需服务器与网络。
- 进度：写在浏览器 `localStorage`（键 `mc.prog`），只在本机，不跨设备同步。
- 深链：`课程文件.html#节id`，例如 `02-微积分真题课.html#s2-12`；首页也支持 `index.html#s2-12` 自动跳转。
- 手机：360 / 390px 已逐节检查，页面级横向溢出为 0；超宽公式可横向滑动并带提示。
